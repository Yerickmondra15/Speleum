# Speleum

Speleum es un proyecto de videojuego web desarrollado como propuesta final, orientado a ofrecer una experiencia interactiva desde el navegador.

El sistema fue construido como una aplicación web moderna, con una estructura organizada por rutas, componentes y vistas. Su enfoque principal en esta etapa es presentar una base funcional del proyecto, con interfaz propia, navegación entre pantallas, manejo de usuario y módulos de juego integrados dentro del mismo entorno.

## Descripción del proyecto

El proyecto consiste en una plataforma web con temática de juego, en la que el usuario puede acceder a distintas secciones del sistema, interactuar con la interfaz y utilizar funciones principales relacionadas con el flujo del videojuego.

Speleum busca demostrar el desarrollo de un sistema estructurado, visualmente coherente y técnicamente organizado, aplicando principios de diseño de software, modularidad y desarrollo web.

## Objetivo

Desarrollar un videojuego web funcional, estructurado y documentado, que permita demostrar conocimientos en:

- diseño de interfaces
- organización modular del código
- desarrollo con tecnologías web modernas
- control de flujo del usuario dentro del sistema
- construcción de una base escalable para futuras ampliaciones del proyecto

## Ejecución del proyecto

1. Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
cd <NOMBRE_DEL_PROYECTO>
```

2. Instalar dependencias:

```bash
npm install
```

3. Ejecutar el entorno de desarrollo:

```bash
npm run dev
```

4. Abrir en el navegador:

```bash
http://localhost:3000
```
